# UWB 远距离测试计划

> 创建时间: 2026-05-11

## 背景

当前 UWB 通信测试均在近距离 (桌面/室内) 环境完成, 丢包率稳定在 ~0.6%.
为验证系统在实际部署场景下的可靠性, 需进行远距离 (10m+) 测试.

## 问题

远距离测试时, Tag 和 PC 之间无法保持串口直连:

- 串口线长度有限 (通常 < 3m)
- USB 延长线信号衰减严重
- Tag 是移动端设备, 需要自由移动

## 解决方案: Tag SD 卡暂存 + Anchor 串口录制

### 架构

```
[远距离测试现场]

  Anchor ─── USB串口 ─── PC (record_anchor.py 实时录制 Anchor 日志)
   │
   │  UWB 无线通信 (10m+)
   │
  Tag ─── SD 卡 (固件自动写入日志)

[测试结束后]

  Tag SD 卡 ──拷贝 tag_*.log──> PC 日志目录
  运行 analyze_logs.py 离线分析 Tag + Anchor 日志
```

### 工作流

1. **录制阶段**

   - Tag 固件启用 SD 卡日志功能, 自动将串口级日志写入 SD 卡
   - PC 端运行 `record_anchor.py` 通过串口录制 Anchor 日志
   - 将 Tag 移动到目标测试距离, Anchor 保持与 PC 连接
2. **数据回收**

   - 测试结束后, 取出 Tag 的 SD 卡
   - 将 SD 卡中的 Tag 日志文件拷贝到 Anchor 日志同目录
   - 日志文件命名需符合 `tag_*.log` 格式
3. **离线分析**

   - 运行 `analyze_logs.py <日志目录>` 进行完整分析
   - 分析脚本自动识别 tag_*.log 和 anchor_*.log 文件
   - 分析内容与 v2 一致 (SPI健康/通信统计/时序分析/槽参数建议)

### 日志目录结构

```
scripts/slot-v3/logs/
  20260511_150000/              # 实验时间戳
    anchor_20260511_150000.log  # PC 串口录制 (record_anchor.py)
    tag_20260511_150000.log     # 从 Tag SD 卡拷贝 (手动)
    session_info.txt            # 录制元信息
    report_20260511_160000.txt  # 离线分析报告
```

## 测试计划

| 距离 | 预期丢包率 | 持续时间 | 备注     |
| ---- | ---------- | -------- | -------- |
| 1m   | < 1%       | 5min     | 基准测试 |
| 5m   | < 5%       | 10min    | 室内     |
| 10m  | < 10%      | 10min    | 室内走廊 |
| 20m  | TBD        | 10min    | 室外空旷 |
| 50m  | TBD        | 10min    | 室外空旷 |

## 关注指标

1. **丢包率** 随距离变化趋势
2. **RX_ERR 分布** 是否出现新的错误模式
3. **PHY RTT** 是否随距离增加 (理论上空口传播延迟可忽略)
4. **Anchor 处理延迟** 是否受距离影响
5. **槽参数** 是否需要针对远距离场景调整
