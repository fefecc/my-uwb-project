# 最小测试环路

## 目的

验证 plan-v4 数据帧链路在不破坏测距的情况下可完成一次端到端数据拉取。

测试只覆盖正常路径:

- Anchor 上电准备固定假数据。
- Tag 持续测距并发现 Anchor。
- Tag APP 选择一个 Anchor 发起数据会话。
- Tag 拉取 meta 和所有分片。
- Tag 校验 CRC 后打印完整数据。
- 测试期间 TWR 事件持续上报。

## 假数据

当前代码中 Anchor 假数据为 5 句英文:

```
Hello from Anchor! This is sentence one for testing.
UWB data transfer works. This is sentence two.
STM32H7 + DW1000. This is sentence three.
FreeRTOS RTOS running. This is sentence four.
Data link complete. This is sentence five.
```

长度计算:

| 行 | 字节数 |
|----|--------|
| 1 | 52 |
| 2 | 46 |
| 3 | 41 |
| 4 | 45 |
| 5 | 42 |
| 换行符 | 4 |
| 合计 | 230 |

按 62 字节净载荷分片:

```
ceil(230 / 62) = 4 fragments
```

## 预期流程

```
Tag APP
  -> LINK_CMD_SEND_CFG_REQ(target_id, session_id)
  <- DATA_ACK

  -> LINK_CMD_SEND_CTRL(GET_INFO)
  <- DATA_FRAG(meta: data_len=230, total_frags=4, total_crc)

  -> LINK_CMD_SEND_CTRL(PULL, frag=1)
  <- DATA_FRAG(data #1)

  -> LINK_CMD_SEND_CTRL(PULL, frag=2)
  <- DATA_FRAG(data #2)

  -> LINK_CMD_SEND_CTRL(PULL, frag=3)
  <- DATA_FRAG(data #3)

  -> LINK_CMD_SEND_CTRL(PULL, frag=4)
  <- DATA_FRAG(data #4)

  -> LINK_CMD_SEND_CTRL(DONE)
  <- DATA_ACK
```

## 验收日志

Anchor 上电:

```
[APP] START short=0x.... role=ANCHOR
[APP] TX buf len=230
[APP] > Hello from Anchor! This is sentence one for testing.
[APP] > UWB data transfer works. This is sentence two.
[APP] > STM32H7 + DW1000. This is sentence three.
[APP] > FreeRTOS RTOS running. This is sentence four.
[APP] > Data link complete. This is sentence five.
```

Tag 完成拉取:

```
[APP] SESSION_COMPLETE anchor=0x....
[APP] < Hello from Anchor! This is sentence one for testing.
[APP] < UWB data transfer works. This is sentence two.
[APP] < STM32H7 + DW1000. This is sentence three.
[APP] < FreeRTOS RTOS running. This is sentence four.
[APP] < Data link complete. This is sentence five.
```

测距持续性:

```
[LINK] TWR anchor=0x....
[APP] SS-TWR anchor=0x.... dist=...
```

在数据会话期间仍应周期性出现 TWR 日志, 不允许 300ms 以上完全没有测距事件。

## 通过标准

| 项目 | 标准 |
|------|------|
| Anchor 假数据 | 上电打印 5 句, `TX buf len=230` |
| CFG | Tag 收到 ACK, Anchor APP 收到 DATA_CFG |
| META | Tag 收到 meta, `data_len=230`, `total_frags=4` |
| DATA | Tag 收齐 4 片, 单片 CRC 通过 |
| DONE | Tag 收到 ACK, 双方 DATA 会话回到 IDLE |
| 测距 | 会话期间 TWR 事件继续出现 |
| 复位 | DATA 失败时只清理 DATA 资源, DISC/TWR 继续 |

## 不测试

- 随机丢包和长时间弱信号。
- 多 Anchor 并发数据会话。
- ERROR/WAIT 的全部异常组合。
- GNSS/IMU/SD 存储链路。
