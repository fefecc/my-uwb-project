# 信号质量采集与存储方案

## 目标

在 PHY 层收帧时，读取 DW1000 完整的接收诊断数据，存入 slot，随 TWR 测距结果一起写入 SD 卡。
存原始值，不做换算，上层自己处理。

## 现状

当前 PHY 收帧时只读了 `rx_pacc`（来自 RX_FINFO 寄存器），`UwbRxQuality` 其余字段全部为 0：

```c
// uwb_phy.c:481-483
memset(&s->quality, 0, sizeof(s->quality));
s->quality.rx_pacc = (uint16_t)((frame_info & RX_FINFO_RXPACC_MASK) >> RX_FINFO_RXPACC_SHIFT);
```

DecaDriver 提供了 `dwt_readdiagnostics()` 一次读完全部诊断数据，但当前没有调用。

SD 卡输出只有 `range_quality`（即 `rx_pacc` 单个值），缺少其他质量指标。

## DW1000 可用诊断数据

`dwt_readdiagnostics()` 一次 SPI 读取，返回 `dwt_rxdiag_t`：

| 字段 | 寄存器 | 含义 |
|------|--------|------|
| `rxPreamCount` | RX_FINFO | 前导码累积计数 (即 pacc) |
| `firstPath` | LDE | 首径索引 (10.6 定点) |
| `firstPathAmp1` | RX_TIME+7 | 首径幅度 1 |
| `firstPathAmp2` | RX_FQUAL+2 | 首径幅度 2 |
| `firstPathAmp3` | RX_FQUAL+4 | 首径幅度 3 |
| `stdNoise` | RX_FQUAL+0 | 噪声标准差 |
| `maxNoise` | LDE_THRESH | 最大噪声 |
| `maxGrowthCIR` | RX_FQUAL+6 | CIR 最大增长 |

这些都是 uint16，共 8 个字段 = 16 字节。

## 改动方案

### 1. slot 中已有 `UwbRxQuality`，补全读取

`UwbRxQuality` 定义（`uwb_stack_types.h`）已经预留了所有字段：

```c
typedef struct {
    uint16_t rx_pacc;        /* ✓ 当前在读 */
    uint16_t fp_index;       /* ✗ firstPath */
    uint16_t fp_ampl1;       /* ✗ firstPathAmp1 */
    uint16_t fp_ampl2;       /* ✗ firstPathAmp2 */
    uint16_t fp_ampl3;       /* ✗ firstPathAmp3 */
    int16_t  rx_power_dbm_x100;  /* ✗ 接收功率 dBm*100 */
    int16_t  fp_power_dbm_x100;  /* ✗ 首径功率 dBm*100 */
    uint16_t std_noise;      /* ✗ 标准噪声 */
    uint16_t max_noise;      /* ✗ 最大噪声 */
    uint16_t lde_status;     /* ✗ */
    uint32_t rx_error_flags; /* ✓ RX 错误时填充 */
} UwbRxQuality;
```

结构体已定义好，只需要在 PHY 收帧时调用 `dwt_readdiagnostics()` 填充。

### 2. PHY 层改动

位置：`uwb_phy.c` 收帧处理（第 481 行附近）

```c
// 之前
memset(&s->quality, 0, sizeof(s->quality));
s->quality.rx_pacc = (uint16_t)((frame_info & RX_FINFO_RXPACC_MASK) >> RX_FINFO_RXPACC_SHIFT);

// 之后
{
    dwt_rxdiag_t diag;
    dwt_readdiagnostics(&diag);

    s->quality.rx_pacc  = diag.rxPreamCount;
    s->quality.fp_index = diag.firstPath;
    s->quality.fp_ampl1 = diag.firstPathAmp1;
    s->quality.fp_ampl2 = diag.firstPathAmp2;
    s->quality.fp_ampl3 = diag.firstPathAmp3;
    s->quality.std_noise = diag.stdNoise;
    s->quality.max_noise = diag.maxNoise;

    // 接收功率计算 (DW1000 用户手册 4.7.2)
    // RX_POWER = 10 * log10( (A^2 + B^2 + C^2) / N^2 ) - C
    // 这里存原始值即可，上层自己算
}
```

**SPI 开销：** `dwt_readdiagnostics()` 是一次 burst read（约 20 字节），在 20MHz SPI 上约 1us，不影响实时性。

### 3. LINK 层

不需要改动。`UwbTwrExchange` 已包含 `UwbRxQuality quality`，从 slot 直接拷贝。

### 4. APP 层改动

`AppUwbSample` 扩展，加入完整的质量数据：

```c
typedef struct {
    uint16_t anchor_id;
    uint16_t tag_id;
    uint16_t exchange_seq;
    uint16_t response_slot_id;
    uint16_t status_flags;
    double   distance_m;
    uint8_t  retry_count;

    /* ★ 新增: 完整信号质量原始数据 */
    uint16_t rx_pacc;
    uint16_t fp_index;
    uint16_t fp_ampl1;
    uint16_t fp_ampl2;
    uint16_t fp_ampl3;
    uint16_t std_noise;
    uint16_t max_noise;

    uint64_t tag_tx_ts;
    uint64_t anchor_rx_ts;
    uint64_t anchor_tx_ts;
    uint64_t tag_rx_ts;
} AppUwbSample;
```

`publish_range_result` 填充新字段：

```c
node.payload.uwb.rx_pacc    = result->quality.rx_pacc;
node.payload.uwb.fp_index   = result->quality.fp_index;
node.payload.uwb.fp_ampl1   = result->quality.fp_ampl1;
node.payload.uwb.fp_ampl2   = result->quality.fp_ampl2;
node.payload.uwb.fp_ampl3   = result->quality.fp_ampl3;
node.payload.uwb.std_noise  = result->quality.std_noise;
node.payload.uwb.max_noise  = result->quality.max_noise;
```

需要让 `UwbRangeResult` 也携带完整 `UwbRxQuality`（目前只有 `range_quality` 即 pacc）：

```c
typedef struct {
    uint16_t anchor_id;
    uint16_t tag_id;
    uint16_t exchange_seq;
    uint16_t response_slot_id;
    uint16_t status_flags;
    double   distance_m;
    uint8_t  retry_count;

    UwbRxQuality quality;    /* ★ 替代原来的 int16_t range_quality */

    uint64_t tag_tx_ts;
    uint64_t anchor_rx_ts;
    uint64_t anchor_tx_ts;
    uint64_t tag_rx_ts;
} UwbRangeResult;
```

### 5. SD 卡输出格式

当前 SD 日志行：

```
UWB,week,sec,ms,valid,anchor,tag,seq,slot,flags,dist,pacc,retry,t1,t2,t3,t4
```

改为：

```
UWB,week,sec,ms,valid,anchor,tag,seq,slot,flags,dist,retry,pacc,fp_idx,fp_a1,fp_a2,fp_a3,noise_std,noise_max,t1,t2,t3,t4
```

质量字段插在 retry 后面、时间戳前面。都是 uint16，用 `%u` 格式化即可。

## 改动范围

| 文件 | 改动 |
|------|------|
| `uwb_phy.c` | 收帧时调用 `dwt_readdiagnostics()` 填充完整 quality |
| `uwb_stack_types.h` | `UwbRangeResult` 中 `int16_t range_quality` → `UwbRxQuality quality` |
| `app_types.h` | `AppUwbSample` 增加 7 个 uint16 质量字段，去掉 `int16_t range_quality` |
| `uwb_app.c` | `publish_range_result` 填充质量字段；日志格式更新 |
| `app_tasks.c` | SD 卡 UWB 输出格式增加质量列 |

### 不改的

- `UwbRxQuality` 结构体定义（已经够用）
- `UwbTwrExchange` 定义（已有 `UwbRxQuality quality`）
- LINK 层（透传 quality）
- PHY 收发逻辑（只是在 RX 完成后多一次 SPI 读）
