# 本地时钟偏移量方案

## 目标

简化 TimeService 的 UTC 时间获取：PPS 同步时一次性计算 `utc_offset`，之后任意时刻只需 **本地单调时间 + offset** 即可得到 UTC，不再每次查询都做 delta 运算。

## 现状问题

当前实现 ([time_service.c](../../APP/service/time_service.c))：

```
PPS 时:   记录锚点 (local_anchor, utc_anchor)
查询时:   delta = local_now - local_anchor
          utc_now = utc_anchor + delta
```

每次 `TimeService_GetTimestamp` 都要：
1. 关中断读 local_clock {sec, ms}
2. 关中断读 utc_anchor + local_anchor
3. 计算 delta（浮点减法 + 秒/毫秒拼接）
4. delta 加到 UTC（除法取模换算 week/week_ms）

**问题：** 步骤 3、4 是纯算术冗余。锚点不变（两次 PPS 之间），`utc_offset = utc_anchor - local_anchor` 是常量，没必要每次重算。

## 新方案

```
PPS 时:   utc_offset = utc_at_pps - local_at_pps      (算一次)
查询时:   utc_now = local_now + utc_offset              (只加一次)
```

核心思路：**把 delta 计算提前到 PPS 同步时刻，查询路径变成一次加法。**

## 本地单调时间

TIM16 配置（CubeMX 已固定，不改）：

| 参数 | 值 | 说明 |
|------|-----|------|
| 时钟源 | 240 MHz (APB2) | STM32H743 |
| Prescaler | 11999 | → 240MHz / 12000 = **20 kHz** |
| Period (ARR) | 19999 | → 20000 计数 = **1 秒** |
| 溢出中断 | 1 Hz | `g_local_sec_count++` |

**单调时间戳 = `sec_count * 1000 + CNT * 1000 / 20000`**

合并为一个 `uint64_t` 毫秒值（自开机起单调递增，永不回绕）：

```
local_ms = sec_count * 1000 + (uint64_t)CNT * 1000 / 20000
```

CNT 范围 0..19999，乘 1000 后仍在 uint32_t 内，不溢出。

## 偏移量计算

### 数据结构

```c
typedef struct {
    uint32_t week;
    uint32_t week_ms;       /* 0 .. 604799999 */
} TimeUtcClock;

typedef struct {
    int64_t offset_ms;      /* utc_ms_from_epoch - local_ms_from_boot */
    bool    valid;
    uint32_t sync_seq;
} TimeUtcOffset;

typedef struct {
    uint64_t local_ms;      /* 单调时间 ms */
    TimeUtcClock utc;
    bool utc_valid;
    TimeSyncState sync_state;
} TimeTimestamp;
```

### PPS 同步（每次 PPS 秒脉冲）

```
local_at_pps = read_local_ms()                       // 读本地单调时间
utc_at_pps   = gnss_utc_cache + 1000ms               // PPS 对齐到下一整秒

utc_epoch_ms = utc_at_pps.week * 604800000 + utc_at_pps.week_ms
offset_ms    = utc_epoch_ms - local_at_pps            // 一次性算好
```

只需算一次，存入 `g_utc_offset.offset_ms`。

### 查询 UTC（任意时刻）

```
local_now      = read_local_ms()                      // 读本地单调时间
utc_epoch_now  = local_now + g_utc_offset.offset_ms   // 一次加法

// 拆回 week + week_ms
week     = utc_epoch_now / 604800000
week_ms  = utc_epoch_now % 604800000
```

## 读本地单调时间（无锁优化）

当前实现用关中断保护 `sec_count + CNT` 的一致性。新方案延续同样的策略：

```c
static uint64_t read_local_ms(void)
{
    uint64_t sec = g_local_sec_count;          // 1 Hz ISR 更新
    uint32_t cnt = __HAL_TIM_GET_COUNTER(&htim16);  // 0..19999

    // 处理竞态：中断已触发但 sec 还没 +1
    if (__HAL_TIM_GET_FLAG(&htim16, TIM_FLAG_UPDATE) != RESET &&
        cnt < 10000U) {
        sec++;
    }

    return sec * 1000U + (uint64_t)cnt * 1000U / 20000U;
}
```

## 方案对比

| | 现状 | 新方案 |
|---|---|---|
| PPS 时 | 存两个锚点 (local + utc) | 算一次 offset |
| 查询时 | delta 计算 + UTC 拼接 | 一次加法 |
| 查询路径运算 | 浮点减法 + 浮点乘加 | 整数加法 + 一次除法取模 |
| 中断内 | 存两个结构体 | 存一个 int64_t |
| 本地时间格式 | {sec, float ms} | uint64_t ms |
| 精度 | ~50us (20kHz CNT 分辨率) | 同，50us |
| 一致性 | 关中断读两组数据 | 关中断读一组 |

## 精度说明

TIM16 计数频率 20 kHz，一个 tick = 50us。

毫秒换算 `cnt * 1000 / 20000` 的截断误差为 0 或 50us，不可改善（除非改定时器配置）。

两次 PPS 之间（最大 1 秒），本地时钟漂移取决于 HSI/HSE 精度，通常 < 1ppm（HSE），即 1us/秒，远小于 50us 分辨率，可以忽略。

## 输出层适配

所有需要记录 UTC 时间的地方（SD 日志、GNSS/IMU/UWB 数据节点）：

```c
// 之前
TimeTimestamp ts;
TimeService_GetTimestamp(&ts);
// 用 ts.local_utc.week, ts.local_utc.week_ms

// 之后 —— 接口不变，内部更快
TimeTimestamp ts;
TimeService_GetTimestamp(&ts);
// 同样用 ts.utc.week, ts.utc.week_ms，只是内部计算从浮点减法变成整数加法
```

**对外接口不变**，改动完全封装在 `time_service.c` 内部。

## 实施范围

只改 `APP/service/time_service.c`，不动 `.h` 里的公开类型签名。

### 内部改动

1. `g_utc_offset` 替代 `g_utc_anchor`
2. `read_local_ms()` 返回 `uint64_t` 替代 `read_local_clock_unlocked()` 返回 `{sec, ms}`
3. `TimeService_OnPpsIrq` 计算 offset
4. `TimeService_GetTimestamp` 用加法替代 delta
5. `TimeService_GetLocalClock` 返回从 `local_ms` 拆出的 `{sec, ms}`（保持兼容）

### 不改的

- TIM16 CubeMX 配置
- PPS 中断入口
- `TimeTimestamp` / `TimeUtcClock` 公开类型
- 调用方代码（app_tasks, storage_service 等）
