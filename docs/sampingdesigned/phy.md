# phy层基本结构


下文中的伪代码使用文字描述
超时时间的变量使用 timeout来描述

phy-state = 监听模式/工作模式；

while{

    if(中断或link层通知 超时时间){
        中断消息的通知预处理一下，简单解析中断的类型，发送完成，接收完成主要是这两个，超时时间会在状态机中调整，除了监听模式下不需要超时时间，剩下的给我设置超时时间为50ms。
        link层通知除非紧急情况，是不会出现这个消息通知的。比如复位的命令等操作 。
    }

    if（ phy-state != 监听模式 ）{
        //工作模式，这个模式下解析命令流，命令流使用计数模式，直到计数值走到最后，退出工作模式，进入监听模式。
    }
    else{
        读取队列消息。
    }

   



    switch(state){
        case:
            立即发送
            switch{
                case:发送打包数据；(修改超时时间为50ms)
                case:等待发送结束；进入监听
            };
        case:
            延时发送
            switch{
                case:发送打包数据；(修改超时时间为50ms)
                case:等待发送结束；；进入监听
            }；
        case:
            槽接收
            switch{
                case：开启接收；
                case: 接收完成；
                case：读取必要的参数；进入监听
            }；
        case:
                监听
                监控外部的消息，一直接收；
                同上槽接收的过程，但是不设置超时时间；
        case：
                error;
    }
}
