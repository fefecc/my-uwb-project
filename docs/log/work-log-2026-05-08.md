# 工作日志 2026-05-08

## 本次修改

- 缩短 UWB LINK 的轮询周期，从 `100ms` 调整为 `10ms`
- 将 LINK 等待 PHY 终态的超时时间从 `500ms` 调整为 `30ms`
- 修正 `LINK -> PHY` 发送后的等待顺序，先置位超时标记，再通知 PHY
- 修正 `TX_DONE` 不再提前清掉超时状态，避免 ACK 未返回时链路假死
- 在 `DISCOVERY_ACK`、`RX_TIMEOUT`、`HW_ERROR` 场景下清理超时标记，保证链路可复位重试
- 保留 `PHY_RESET` 兜底路径，超时后直接复位 DW1000

## 影响范围

- `APP/UWB/uwb_stack_types.h`
- `APP/UWB/uwb_link.c`

## 当前效果

- Discovery 最小环路有了短超时保护
- 任一环节无响应时，LINK 会在较短时间内触发 DW1000 复位
